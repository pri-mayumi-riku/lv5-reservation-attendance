# 習い事の教室の予約・出欠表

## 公開URL
- https://pri-mayumi-riku.github.io/lv5-reservation-attendance/

## 依頼文
「小さな習い事の教室をやっています。生徒には月の初めに通う日を予約してもらい、紙の出欠表に書いています。
急な欠席の連絡を電話やメッセージでもらっても、紙に書き忘れて、来ない生徒を待ってしまうことがあります。
紙をやめて、その日に来る人をすぐ確かめられるようにしたいです。」

## 「急な欠席を書き忘れて、来ない生徒を待ってしまう」がどう解決したか
生徒から急な欠席の連絡を受けたら、その場でタブレットから当日の出欠確認画面を開き、その生徒の「欠席にする」ボタンを押すだけで欠席が記録・保存されるため、紙を探して書く手間がなくなり、後回しにして書き忘れることが起きにくくなります。当日の出欠確認画面では、「出席予定」と「欠席」の生徒がそれぞれ人数つきで一覧で表示されるため、今日来る生徒が一目でわかり、来ない生徒を待たずに済みます。

## 前提
- サーバやログインは使わず、教室に置いたタブレット1台のブラウザの中で完結させる
- 生徒からの連絡は、これまでどおり電話やメッセージで先生に届く。ページを操作するのは先生だけとする
- 解決する対象は「連絡を受けたその場ですぐ記録でき、当日に来る人をひと目で確かめられること」とする

## 要件
### 予約の登録・削除
- 先生は、予約管理画面で予約の登録・削除を行う
- 予約は日単位（1日1コマ）で行う
- 先生は、生徒と日付を選択して予約を登録でき、登録した予約は「出席予定」になる
- 複数の日付を選択して予約を登録・削除できる
- 先生が予約内容を間違えても、予約を削除できる
- 同じ生徒を同じ日に重複して予約することはできない
- 過去の日付（今日より前）は、予約の登録・削除ができない。

### 当日の出欠確認
- ページを開いたときに、今日の出欠確認画面が表示され、今日の予約・出欠内容が表示される
- 画面は「出欠確認」と「予約管理」の2つのタブで構成され、先生が切り替えられる
- 表示中の日付は常に表示する
- 出欠確認画面では、実際に出席したかどうかの確認までは行わない
- 予約している生徒が「出席予定」「欠席」で分かれて一覧表示され、それぞれの人数や名前も確認できる
- 先生は、日付を切り替えて他の日の予約内容も確認できる
- その日の予約が0件の時は、予約がないことがわかる表示になる
- 過去の日付は出欠の変更はできない

### 急な欠席の記録
- 先生が生徒から当日に急な欠席連絡を受けた時、当日の出欠画面でその生徒を1タップで「欠席」に変更できる
- 前日以前に欠席連絡を受けた際は、その日に予約していた生徒を「欠席」にできる
- 欠席理由の記録までは行わない
- 生徒を間違えて「欠席」にしても、「出席予定」に1タップで戻せる

### システム要件・制約
- 画面幅768px（タブレットの幅）でも横スクロールせずに操作できる
- 生徒の名前はすべて架空の名前にする
- 生徒は、あらかじめ初期データとして固定して登録しておく
- 生徒の追加・削除・名前変更は行わない
- 今日の日付は、タブレット（ブラウザ）の現在の日付とする
- ページを再読み込みしても、登録した予約と出欠データが localStorage に残る

### 画面一覧

| 画面 | できること |
|---|---|
| **出欠確認画面（タブ）** | ・ページを開くと今日の予約と出欠内容が表示される<br>・日付を変更して他の日の予約と出欠内容を確認できる<br>・「出席予定」「欠席」の生徒をそれぞれ別々の一覧で、人数と名前つきで確認できる<br>・「欠席にする」「出席予定に戻す」ボタンで出欠状態を1タップで変更できる（過去の日付は変更不可）<br>・予約がない日は「予約がありません」と表示される<br>・予約管理画面に切り替えられる |
| **予約管理画面（タブ）** | ・生徒と日付を選んで予約を登録できる<br>・登録済みの予約を選んで削除できる<br>・出欠確認画面に切り替えられる |

## 確かめ方

| ID | 手順 | 期待される結果 |
|---|---|---|
| 1 | 予約管理画面でその日の予約を2人分登録し、その内1人を「欠席」にした状態で、その日の出欠確認画面を開く | 「出席予定」に1人、「欠席」に1人が別々の一覧で表示され、人数や名前も合っている |
| 2 | 予約管理画面で任意の生徒を予約し、その生徒に対して「欠席にする」ボタンを押す | 出欠確認画面でその生徒が即座に「欠席」の一覧に移る |
| 3 | 「欠席」の生徒に対して「出席予定に戻す」ボタンを押す | 出欠確認画面でその生徒が即座に「出席予定」の一覧に戻る |
| 4 | 予約が1件もない日付を選択して表示する | 「予約がありません」などの表示が出る |
| 5 | 予約管理画面で任意の生徒を選び、2つ以上日付を選んで登録し、選んだ日それぞれの出欠確認画面を表示する | それぞれの出欠確認画面でその生徒が「出席予定」で表示される |
| 6 | 予約管理画面で、任意の生徒のその日の登録済みの予約を削除する | その日の出欠確認画面でその生徒が「出席予定」「欠席」のどちらの一覧にも表示されない |
| 7 | 生徒の予約登録や出欠状態を変更したあとブラウザを再読み込みする | 再読み込み前と同じ予約・出欠状態が表示される |
| 8 | 開発者ツールで画面幅を768pxにして操作する | 横スクロールバーが出ず、レイアウトが崩れずにすべての操作ができる |
